Get Your User ID

Required for API access to your workout data

Click the button below to find your Firebase User ID. You'll need this to use the Treadmill Tactician API.

⚠️ Security Note: Your User ID is like a password for your workout data. Keep it private and don't share it publicly.

Using Your User ID

Once you have your User ID, you can access your workout data via API:

  1. Get all workouts:
    GET /getWorkouts?userId=YOUR_USER_ID
  2. Get statistics:
    GET /getStats?userId=YOUR_USER_ID
  3. Export all data:
    GET /exportData?userId=YOUR_USER_ID

See API.md for complete documentation.
